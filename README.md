# JR豊肥本線 リアルタイム運行ボード（立野〜宮地）

JR豊肥本線・立野〜宮地区間の沿線地図上で、現在時刻に合わせて列車が公式ダイヤどおりに走るリアルタイム運行ボードです。

🌐 **公開URL**: https://popsaneshima-design.github.io/houhi-realtime/

スマホからもそのまま閲覧できます。

---

## ✨ 主な機能

### 🚃 リアルタイム運行アニメーション
- 現在時刻と公式ダイヤから各列車の現在位置を計算し、阿蘇地域の地図上を移動
- 1秒ごとに位置を更新（CSS transition で滑らかに補間）
- 進行方向に応じて電車の頭が左右反転
- 立野→赤水の山岳カーブ区間は経由点を設定して実線路に沿って走行

### 🚂 種別ごとの車両デザイン
- **普通／快速**: 旅客車スタイル（青系）
- **九州横断特急**: 流線型・赤の特急スタイル
- **あそぼーい！**: オレンジの観光特急スタイル

### 📍 駅ホバーで次便表示
- 各駅マーカーにマウスを乗せると、その駅から次に発車する列車を上下方向ごとに表示
- 種別・発車時刻・残り時間を一目で確認

### 🎉 リアルタイム トースト
- 列車が出発・各駅到着・終点到着した瞬間にポップアップ通知
- 駅ごとの遊び心ある一言（例: 宮地「阿蘇神社の最寄り駅⛩」）

### 🔍 表示切替
- 「近い列車のみ」: 走行中＋出発10分前以内の列車
- 「全列車表示」: 当日の全列車

### ⏰ デバッグ用：時刻オーバーライド
- `?t=HH:MM` をURLに付けると任意時刻に固定して動作確認できる
- 例: https://popsaneshima-design.github.io/houhi-realtime/?t=10:30

---

## 📊 データソース

- **ダイヤ**: JR九州 駅別時刻表（2026年5月時点）
- **路線図**: 阿蘇地域観光案内マップ
- **対象区間**: JR豊肥本線 立野〜宮地（7駅・21.1km）
  - 立野 / 赤水 / 市ノ川 / 内牧 / 阿蘇 / いこいの村 / 宮地

中間駅の通過時刻は、立野駅・阿蘇駅・宮地駅の実発車時刻と種別ごとの所要時間表をもとにした概算です。

## ⚠️ 注意事項

- 本サイトは個人制作の非公式ツールです
- 表示時刻は公式ダイヤに基づきますが、実際の運行状況（遅延・運休等）は反映されません
- 平日ダイヤをベースとしており、土休日は一部「快速」運転に変更があります
- 正式な運行情報は[JR九州公式](https://www.jrkyushu.co.jp/)をご確認ください
